1. 왜 이 주제인가

기획 의도

배틀로얄에서 제3자 개입은 정상이다.
문제는 손해를 만회할 수 없을 때다.

  • 예측하거나 대응할 수 없는 개입으로 입은 손해를 한 판 내내 복구하지 못하면, 1등을 노리는 게임이 아니라 점수를 지키는 게임이 된다.
  • 재미는 손해가 납득 가능하고 만회가 가능할 때 성립한다고 보고, 세 시스템에서 이를 해치는 요소를 주제로 골랐다.

2. 한 장 요약

세 파트의 문제, 개발진의 시도, 제안

01 안전지대 / 제3자 개입

문제
예측/대응할 수 없는 개입으로 입은 손해를 복구하지 못함
개발진의 시도
공간/시간 설계 → 인지/보상 → 분산/가속 → 규칙 교체(12.0)
제안
접근 경고, 손해 복구 보정, 점수 구조 검토

02 루트 고착화

문제
같은 루트(아이템 세팅을 맞추는 파밍 동선)가 반복되며 초반 양상이 같아짐
개발진의 시도
시즌 시작 재료 재배치(11.0, 12.0), 시즌 중 안내 강화(12.2, 12.3, 12.5)
제안
예고형 재료 변동: 판마다 일부 재료 위치만 바꾸고 게임 시작 때 공개

03 상자 / 보급 파밍

문제
고가치 보상 오브젝트가 획득 시간 격차와 몰림을 만듦
개발진의 시도
가속 연동 보급 감소, 보리 반복 조정, 경찰서 상자 개편(11.4)
제안
보리 상자 20초 고정 시간 획득

3. 사례 연구 : 안전지대 / 제3자 개입

문제 → 근거 → 제안 → 한계와 검증 계획

01

문제 : 개입은 문제가 아니다

개입을 없애는 것이 아니라, 예측 가능성과 복구 가능성을 높인다.

  • 문제 삼지 않는 것: 제3자 개입 그 자체, 정보 싸움으로 대비할 수 있는 개입, 개입으로 이득을 보는 플레이
  • 문제 삼는 것: 예측할 수 없는 개입에 대비할 수단 부족, 손해를 한 판 내내 복구하지 못함, 순위 방어만 하게 됨
02

근거 : 4차에 걸친 개편

대응은 개입 빈도와 개입 직후에 집중. 사전 예측과 손해 후 복구는 비어 있다.

  • ① 공간/시간 설계 (1.4, 1.7, 1.11) → ② 인지/보상 (1.22 ~ 9.4) → ③ 분산/가속 (9.7 ~ 11.0) → ④ 규칙 교체 (12.0 ~ 12.5)
  • 사전 예측 수단은 균열(별도 전투 공간) 안에 한정
  • 손해 후 복구는 초반 자동 부활, 크레딧 부활, 숙련도 보정(1.11) 수준
03

제안 : 빈 축을 메우는 세 가지

우선순위 A → B → C. 구현 부담이 작은 것부터.

  • A 접근 경고 (사전 예측): 균열 알림(9.7)을 일반 교전으로 확장, 난입 어나운스의 앞 단계
  • B 손해 복구 보정 (손해 후 복구): 기존 복구 장치를 개입 손해에 맞춰 확장
  • C 점수 구조 검토 (손해 후 복구): 기존 손실 보전의 확장, 랭크 점수를 건드려 검증이 가장 많이 필요
04

한계와 검증 계획

사례는 유저 인식의 예시이지 통계가 아니다.

  • 한계: 커뮤니티 사례는 한 커뮤니티의 글 3건, 반대 의견 미포함, 12.0 이후 여러 패치가 겹쳐 효과 분리가 어려움
  • 검증: 여러 판의 캐릭터 선택 화면에서 지역별 시작 인원 기록, 패치 전후 공개 지표(평균 순위, TOP3 비율 등) 조사
  • 적용: 일부 모드, 티어에 한정한 시범 적용으로 효과 측정

4. 같은 방향의 두 제안

루트 고착화, 상자 / 보급 파밍

예고형 재료 변동

판마다 일부 재료(예: 2~3종)의 생성 지역을 후보 안에서 바꾸고, 게임 시작 때 공개해 루트 화면에 반영한다.

보리 상자 고정 시간 획득

획득 단계를 20초 고정 상호작용으로 바꿔 캐릭터 편차를 없애고, 노출 시간을 모두가 예측할 수 있게 한다.

세 파트의 공통 해법 : 예측 가능성, 복구 가능성, 다양성
