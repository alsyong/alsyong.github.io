핵심 재미 · 성취감

재미는 해냈다고 느끼는 순간 가장 크게 다가온다고 보고, 성취감 하나에 집중했습니다. 별 3개를 모두 얻는 것이 목표입니다.

① 장애물 돌파자동 장애물의 패턴을 읽고, 레버나 버튼을 찾아 수동 장애물을 열며 통과 방법을 직접 찾게 했습니다.
② 별 획득별의 위치를 알려 주지 않고, 표지판과 특이 발판을 단서로 직접 찾게 했습니다.

나의 작업

  • 조작·점프: 점프를 모든 행동의 기본 조작으로 두고, 점프 높이, 체공 시간, 이동 속도를 직접 조정
  • 획득 요소: 별 3개를 탐험의 목표로 두고 배치 설계
  • 모션·이펙트·UI: 점프, 착지, 별 획득이 화면에서 바로 읽히도록 모션·이펙트를 직접 제작하고, 별 개수·체력·남은 시간 UI 구성
  • 수치와 동작은 프로그래머와 협의하며 플레이로 확인

결과 · 배운 점

지스타 출품을 목표로 플레이 가능한 프로토타입을 완성했습니다.

멀티가 가능하게 된다면 확실히 재미있고 경쟁력이 있을 것 같다지스타 출품 심사 피드백

여러 재미 요소를 구상했던 초기와 달리, 개발 과정에서 핵심 재미를 명확히 정하고 그 재미에 집중하도록 기획을 수정했습니다.

사례 연구: 안전지대 / 제3자 개입

  1. 01

    문제

    제3자 개입 자체는 배틀로얄의 재미다. 예측·대응할 수 없는 개입으로 입은 손해를 한 판 내내 복구하지 못하는 것이 문제다.

  2. 02

    근거

    패치 노트로 4차 개편(1.4 ~ 12.5)을 정리하니, 그동안의 개편은 개입 빈도와 개입 직후를 막는 데 집중했다.

  3. 03

    제안

    개입은 그대로 두고, 기존 개편이 비워 둔 사전 예측과 손해 후 복구를 메운다. A 접근 경고 → B 손해 복구 보정 → C 점수 구조 검토 순서.

  4. 04

    한계와 검증 계획

    커뮤니티 사례 3건은 통계가 아니다. 지역별 시작 인원 기록과 패치 전후 공개 지표로 다시 확인한다.

같은 방향의 두 제안

루트 고착화: 예고형 재료 변동

판마다 일부 재료(예: 2~3종)가 나오는 지역을 미리 정한 후보 중에서 바꾸고, 게임 시작 때 공개해 루트 화면에 반영한다.

상자 / 보급 파밍: 보리 상자 20초 고정 획득

상자를 부수는 대신 20초 고정 상호작용으로 얻게 해 캐릭터별 획득 시간 차이를 없애고, 노출 시간을 모두가 예측할 수 있게 한다.

세 파트의 공통 해법: 예측 가능성, 복구 가능성, 다양성

개요

  • 로스트아크의 일반 몬스터를 분석해, 대부분의 일반 몬스터에 공통으로 적용할 수 있는 범용 AI를 FSM으로 설계

포켓몬챔피언스 배틀 보조 프로그램

Claude Code로 직접 만든 개인 툴

기획 의도

게임에 익숙하지 않으면 상대 파티를 보고도 어떤 포켓몬을 어떤 순서로 내보내고 어떻게 행동할지 판단하기 어렵습니다. 이 막막함을 덜어 주려고 기획했습니다.

동작 흐름

  1. 상대 6마리 입력 (스크린샷, 실시간 화면 인식으로 자동 입력)
  2. 대면 점수, 데미지와 확정 타수 계산 (Pikalytics 통계로 기술·도구 추정)
  3. 선출 3마리, 선봉, 상대별 대처법(유지, 교체, 추천 기술)

나의 기여

  • 추천 기능, 판단 기준, 집계할 통계의 범위를 직접 정의하고 설계
  • 기능을 44개 이상의 단계로 나누어 추가하고, 단계마다 기록
  • 실제 스크린샷으로 검증셋을 만들어 인식 정확도 측정 (검증 42칸 중 41칸)
  • 지인 3명에게 테스트를 요청했고, 현재도 직접 사용 중

다음 계획

현재는 PC 미러링으로만 쓸 수 있어, 모바일 기기에서 바로 쓸 수 있는 앱으로 확장할 계획입니다.

기능 추가 과정

  1. 1
    추천 엔진파티 검증, 선출 추천, 승패 기록 학습
  2. 2
    판단 정교화데미지, 메가진화, 날씨, 조합 평가
  3. 3
    화면 인식스크린샷 자동 인식, 검증 42칸 중 41칸
  4. 4
    실시간 감시창 추적, 아이콘 관리, 저장 후 인식 오류 재검사
